# 알려진 제약과 검증 안내

이 문서는 원본 코드를 읽어 확인한 제약을 기록합니다. MATLAB 실행으로 재현한 결과가 아니며, 원래 프로젝트의 동작을 보존하기 위해 기능 코드는 수정하지 않았습니다.

## 사용 시 참고

| 항목 | 현재 동작·제약 | 사용 방법 / 개선 방향 |
| --- | --- | --- |
| 입력 채널 | STFT 표시, `conv`, phase vocoder, 그레인 처리 등 여러 경로가 모노 벡터를 전제 | 모노 WAV 사용; 향후 채널별 처리 또는 명시적 다운믹스 추가 |
| 샘플레이트 | 업로드 시 8,192 Hz로 변환 | 4,096 Hz 이상 성분을 보존하는 고음질 편집 용도가 아님 |
| 파일 선택 취소 | 파일/경로가 `0`인지 확인하지 않음 | 취소 후 오류가 나면 파일을 다시 선택; 향후 취소 가드 추가 |
| 파일 경로 | 업로드는 `addpath(path)` 후 파일명만 읽음; 저장은 선택 폴더를 `audiowrite`에 전달하지 않음 | 동명 파일을 피하고 저장 전 원하는 폴더를 Current Folder로 설정; 향후 `fullfile` 사용 |
| RESET | 업로드 때의 리샘플링을 다시 수행하지 않음; Layer의 File 1/2가 `filename`을 덮어씀 | 새 실험은 Upload File로 원본을 다시 불러오기 |
| 실행 순서 | 입력을 불러오기 전 버튼을 눌러도 상태 검사가 없음 | Upload File을 먼저 실행; Layer Convolution은 두 파일 선택 후 Compute |
| 필터 | 하한·상한 범위 검증 없음; 기본값은 모두 0 | `0 < lower < upper < fs/2` 만족 필요 |
| 피치 | 변수 이름은 `nsemitones`지만 실제로 양수 비율을 사용하며 0은 우회 처리 | 반음 단위로 해석하지 않기; 1은 피치 비율상 중립값 |
| 템포 | Phase vocoder의 재생 속도 비율로 사용 | 1보다 크면 빨라지고, 1보다 작으면 느려짐 |
| 입력 길이 | Phase vocoder는 1,024 샘플 FFT와 복수 프레임을 전제 | 첫 실험에는 2초 이상 오디오 사용 |
| 그레인 | 10–20 ms 그레인 500개를 무작위 배치; 매우 짧은 입력에서 유효하지 않은 인덱스 가능 | 결과가 실행마다 다를 수 있음; 최소 길이 검사 및 인덱스 경계 처리 필요 |
| 반복 | 횟수의 정수/양수 검증이 없고 기본값 0은 빈 신호를 만듦 | 양의 정수 사용; 메모리 때문에 과도한 반복 피하기 |
| 효과 누적 | 출력 정규화·클리핑 검사가 없음 | 효과를 누적하면 WAV 저장 시 포화 가능; 향후 피크 검사 추가 |
| Display Edit | 복소 STFT를 `imshow`에 직접 전달하고 `close all` 사용; ROI 취소 처리 없음 | 표시 데이터 변환, 창 범위 지정, ROI 상태 검사 필요 |
| Envelope | FM 합성음 추가 기능; `app.t` 길이에 의존 | 편집 후 Play로 시간축 갱신; 별도 진폭 조절기로 해석하지 않기 |
| `schroeder1` | GUI에서 호출하지 않으며 `allpass`, `seriescoefficients` 보조 함수가 아카이브에 없음 | 보존용 실험 코드이며 독립 실행은 보장하지 않음 |

## 확인 완료 범위

- 원본 `.m` 소스 10개와 정리본의 바이트 일치 확인.
- README와 문서의 로컬 링크 및 이미지 경로 확인.
- 발표 자료의 ZIP/XML 무결성 및 학번 제거 확인.
- 게시 대상의 인증정보 패턴과 생성물 포함 여부 점검.
- MATLAB/Octave가 없는 환경이므로 MATLAB 구문 분석, GUI 작동, 오디오 재생 및 처리 결과는 실행 검증하지 않음.

## MATLAB에서 수행할 수동 검증

아래는 실행 완료 보고가 아니라 후속 검증 절차입니다.

1. `examples/generate_demo_audio.m` 실행 후 생성된 모노 WAV의 샘플레이트가 8,192 Hz인지 확인합니다.
2. `app = run_app`으로 GUI를 열고 Upload File → Play → Transform 순서로 파형·스펙트로그램을 확인합니다.
3. 200–1,000 Hz 대역 통과 필터 적용 후 Play/Transform 결과를 비교합니다.
4. 원본을 다시 불러오고 Pitch 0, Tempo 1로 Generate를 시험합니다. 별도 실험으로 Tempo 0.75 / 1.25를 비교합니다.
5. 각각 원본을 다시 불러와 역재생, 반복 2회, 플랜저를 시험합니다. 해당 도구상자가 있으면 리버브도 확인합니다.
6. 두 모노 파일의 Layer Convolution과 그레인 처리를 각각 시험합니다.
7. Current Folder에 저장한 WAV를 다시 읽고 길이·샘플레이트·피크를 확인합니다.
8. Display Edit와 Envelope는 위 제약을 먼저 확인한 뒤 별도로 검증합니다.
